# IluminatecBR — Site institucional

Site estático da **IluminatecBR** — Representante Oficial Signify Philips no Brasil.
Energia · iluminação profissional.

## Estrutura

| Arquivo | Função |
|---------|--------|
| `index.html` | Página principal (one-page) |
| `privacidade.html` | Política de Privacidade (LGPD) |
| `logo/` | Identidade visual — SVG + PNG em todas as versões |
| `.nojekyll` | Desativa o processamento Jekyll do GitHub Pages |
| `CNAME` | Domínio customizado (criado na publicação do domínio) |

## Publicação

Hospedado via **GitHub Pages** (branch `main`, raiz `/`).

## Pendências antes do go-live

- [ ] Trocar o WhatsApp `5531900000000` pelo número real (`index.html`)
- [ ] Inserir o ID do Google Analytics 4 no lugar de `G-XXXXXXXXXX` e descomentar o bloco
- [ ] Registrar o domínio `iluminatec.com.br` e criar o arquivo `CNAME`
- [ ] Substituir os emojis dos produtos por fotos reais do catálogo Signify

## Tecnologia

HTML5 + CSS3 puro, sem framework. Google Fonts: Nunito Sans · DM Sans · DM Mono.
